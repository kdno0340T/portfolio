# Dhanush — Interactive Portfolio

A Next.js portfolio with a Canvas cursor swarm, scroll-linked construction, responsive layouts, and reduced-motion support.

## Run locally

```bash
npm install
npm run dev
```

Profile details, projects, skills, and interests are centralized in `src/data/profile.ts`. The replaceable profile portrait is `public/images/profile/dhanush.jpg`. Add a personal LinkedIn URL to `src/data/profile.ts` to reveal its links.

Production checks: `npm run lint` and `npm run build`.
